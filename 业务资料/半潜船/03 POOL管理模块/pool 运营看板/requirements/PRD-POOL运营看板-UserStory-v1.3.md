## 二、POOL运营看板模块



### US-CAL-001：全局筛选

**作为** 半潜财务人员

**我想要** 按年份、累计截至月份、船舶和经营公司设定看板范围，并可以查询、重置和折叠筛选区

**以便于** 所有经营和燃油模块使用同一统计范围。

**验收标准：**

- [ ] 进入页面和点击重置后，年份为当前年，累计截至月份为当前月，船舶和经营公司为全部。
- [ ] 点击查询后，经营总览、分船、趋势、年度汇总、内贸货、舱租和燃油各区域按该范围刷新。
- [ ] 年份未选择时不能完成查询，并提示具体字段。
- [ ] 船舶可按编码、中文名、英文名搜索并多选；搜索不清除已选项；清空表示全部候选船舶。
- [ ] 经营公司按船东去重，默认全部公司。
- [ ] 各区域内的年月、船舶选择超出全局范围时不允许应用，已不在范围内的船舶自动移除。

**业务规则：**

- **操作规则**：展开或折叠筛选区 → 选择条件 → 点击查询刷新看板；点击重置恢复默认范围。
- **数据规则**：年份、累计截至月份、船舶、经营公司（选择带出）。船舶来自 Budget Analysis 的 Group And Change Amt，按唯一船舶编码去重。经营公司来自航次船东集合并去重。
- **校验规则**：年份必填。累计截至月份表示所选年 1 月至该月，不是单月。区域内筛选不得宽于全局范围。
- **状态逻辑**：未查询前使用默认范围；重置后恢复默认，不把清空理解成无数据。
- **异常场景**：
  - 年份未选择 / 阻断查询并提示具体字段 / 阻断 / 无单独提示文案
  - 区域内年月或船舶超出全局范围 / 自动移除越界船舶 / 阻断该次越界选择 / 无单独提示文案
  - 船舶或经营公司候选项无法加载 / 保留页面，不展示伪造候选项 / 不阻断页面打开 / 无单独提示文案

**数据流与依赖：**

- **上下游模块/系统**：读取 Budget Analysis 的船舶、船东和期间；向 F-CAL-002 至 F-CAL-013 提供查询范围。
- **第三方对接**：无直接对接。
- **定时任务**：无。
- **数据同步**：依赖上游船舶、航次和船东数据已同步。
- **公用数据/表**：全局筛选上下文，供全部看板模块共用。
- **连带影响**：查询或重置后刷新各模块结果；导出使用刷新后的结果，列表按新结果重新分页。
- **权限与数据范围**：半潜财务人员；候选项和结果限于授权经营公司、船舶。业务数据只读。

**前置条件：**

- 用户已登录并拥有看板查询权限。

**后置条件：**

- 页面保持当前全局范围，后续模块都在该范围内计算。

**关联 US：** 下游 US-CAL-002 至 US-CAL-015；关联功能编号 F-CAL-001

**UI 原型：** `POOL运营看板-原型-v1.3.html` 页头筛选区，含查询、重置和折叠。

### US-CAL-002：POOL经营总览

**作为** 半潜财务人员

**我想要** 在当前范围内查看贡献毛利、已分配租金、差额、特殊航次贡献和燃油成本

**以便于** 判断 POOL 当期整体经营结果。

**验收标准：**

- [ ] 展示五类指标：贡献毛利合计、已分配租金合计及占贡献毛利、贡献毛利与租金差额、特殊航次贡献（含内贸货和转手货的金额与航次数）、燃油成本及占贡献毛利。
- [ ] 只汇总航次状态为已完航或 POC 的航次；同一航次只计一次。
- [ ] 已分配租金按切割营运天乘每天租金汇总，单位为万元。
- [ ] 差额大于等于 0 显示“正向结余”，小于 0 显示“租金高于贡献”。
- [ ] 贡献毛利合计为 0 或缺失时，两个占比显示“—”，不按 0 计算。
- [ ] 特殊航次金额按字段口径从 Budget Analysis 汇总。

**业务规则：**

- **操作规则**：进入页面或应用全局筛选 → 汇总并展示指标卡。不要求从指标卡下钻航次。
- **数据规则**：贡献毛利、已分配租金、差额、占比、内贸货贡献及航次数、转手货贡献及航次数、燃油成本（计算）。内贸货按航次归属为内贸货汇总；转手货按互租合同航次汇总。
- **校验规则**：统计期间为所选年 1 月至累计截至月份，并受船舶、经营公司约束。燃油成本按耗油量乘对应船舶 VLSFO 油价后折成万元。
- **状态逻辑**：指标只读。缺失值显示“—”，不把缺失展示成 0。
- **异常场景**：
  - 贡献毛利合计为 0 或缺失 / 占比显示“—” / 不阻断其他指标 / “—”
  - 上游查询失败 / 不展示伪造合计 / 阻断本次结果 / 无单独提示文案

**数据流与依赖：**

- **上下游模块/系统**：读取 Budget Analysis 航次贡献、切割营运天和每天租金；燃油成本读取航次报文耗油量和 SAP 油价。结果仅在本区域展示。
- **第三方对接**：无直接对接。
- **定时任务**：无。
- **数据同步**：依赖预算分析和燃油核算结果已同步。
- **公用数据/表**：与分船、趋势、年度汇总共用已完航或 POC 的贡献和租金口径。
- **连带影响**：无待办、消息或状态回写。
- **权限与数据范围**：半潜财务人员，授权经营公司和船舶，业务数据只读。

**前置条件：**

- US-CAL-001 已形成有效全局范围。

**后置条件：**

- 用户看到当前范围的五类经营指标。

**关联 US：** 上游 US-CAL-001；关联功能编号 F-CAL-002

**UI 原型：** `POOL运营看板-原型-v1.3.html` 经营总览指标卡。

### US-CAL-003：分船贡献与租金差额

**作为** 半潜财务人员

**我想要** 按船比较贡献毛利、已分配租金和差额

**以便于** 识别各船对 POOL 的结余或不足。

**验收标准：**

- [ ] 同一船舶编码只出现一行，展示中文船名、排名、贡献毛利、已分配租金和差额。
- [ ] 默认按差额从高到低，差额相同再按贡献毛利从高到低。
- [ ] 列表、条形图和悬浮提示使用同一差额口径。
- [ ] 只统计已完航或 POC 航次，期间为所选年 1 月至累计截至月份。
- [ ] 本区域不分页，也不能从本区域进入航次明细。

**业务规则：**

- **操作规则**：查看分船区域 → 系统按船汇总并展示排名和条形对比。
- **数据规则**：贡献毛利、已分配租金、差额、排名（计算）；船舶名称（选择带出）。已分配租金等于切割营运天乘每天租金。
- **校验规则**：按唯一船舶编码汇总。差额大于 0 表示贡献高于租金，小于 0 表示租金高于贡献。
- **状态逻辑**：结果只读，跟随全局筛选，没有本区域独立船舶筛选。
- **异常场景**：
  - 当前范围没有符合条件的船舶 / 展示空列表 / 不阻断其他区域 / 提示“暂无数据”
  - 单船贡献或租金缺失 / 该船不按 0 静默补齐后参与排名 / 不阻断其他船舶 / 无单独提示文案

**数据流与依赖：**

- **上下游模块/系统**：读取 Budget Analysis 的航次贡献、切割营运天、每天租金和船舶主数据。不向其他模块回写。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：依赖预算分析数据已同步。
- **公用数据/表**：与经营总览、年度汇总共用贡献和租金口径。
- **连带影响**：无。
- **权限与数据范围**：半潜财务人员，授权经营公司和船舶，只读。

**前置条件：**

- US-CAL-001 已形成有效全局范围。

**后置条件：**

- 用户看到当前范围内按差额排序的分船对比。

**关联 US：** 上游 US-CAL-001；关联功能编号 F-CAL-003

**UI 原型：** `POOL运营看板-原型-v1.3.html`「分船贡献与租金差额」。

### US-CAL-004：月度经营趋势

**作为** 半潜财务人员

**我想要** 按月查看贡献毛利、已分配租金和燃油成本

**以便于** 观察所选累计期间内的月度变化。

**验收标准：**

- [ ] 横轴从所选年 1 月连续展示到累计截至月份。截至月份为 1 月时只有一个点。
- [ ] 每个月单独汇总贡献毛利和已分配租金，且只含已完航或 POC 航次。
- [ ] 每个月单独汇总燃油成本，单位为万元。
- [ ] 某月没有数据时不补 0。
- [ ] 悬浮可查看对应月份的三项数值，口径与折线一致。

**业务规则：**

- **操作规则**：使用全局年份和累计截至月份 → 逐月查询并绘制折线。本区域没有独立月份选择器。
- **数据规则**：月份（系统生成）；贡献毛利、已分配租金、燃油成本（计算）。
- **校验规则**：月份必须落在所选年 1 月至累计截至月份。租金按切割营运天乘每天租金。燃油成本按报文耗油量乘 SAP 中该船 VLSFO 油价。
- **状态逻辑**：跟随全局筛选刷新，图表只读。
- **异常场景**：
  - 某月无经营或燃油数据 / 该月不画成 0 / 不阻断其他月份 / 断点
  - 上游单月查询失败 / 不展示伪造趋势 / 阻断本次图表 / 无单独提示文案

**数据流与依赖：**

- **上下游模块/系统**：按月读取 Budget Analysis；燃油成本读取航次报文和 SAP 油价。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：依赖预算分析和报文、油价已同步。
- **公用数据/表**：与经营总览共用贡献、租金和燃油成本口径，但按单月而不是累计合计。
- **连带影响**：无。
- **权限与数据范围**：半潜财务人员，授权经营公司和船舶，只读。

**前置条件：**

- US-CAL-001 已形成有效全局范围。

**后置条件：**

- 用户看到 1 月至累计截至月份的连续月度趋势。

**关联 US：** 上游 US-CAL-001；关联功能编号 F-CAL-004

**UI 原型：** `POOL运营看板-原型-v1.3.html`「月度经营趋势」折线，支持悬浮查看。

### US-CAL-005：船舶年度经营汇总

**作为** 半潜财务人员

**我想要** 按船查看年度贡献、租金、预算执行、特殊航次、跨年调整、燃油成本和达标状态

**以便于** 核对各船全年预算与累计实际的差距。

**验收标准：**

- [ ] 表头船舶多选只影响本表；未选时展示全局范围内全部船舶。
- [ ] 按所选年份加船舶编码一行一船，默认按贡献差额降序，相同再按贡献毛利降序。
- [ ] 年初指定值为全年考核利润预算，不按累计截至月份折算。
- [ ] 指定差额等于累计实际贡献毛利减全年预算。累计实际大于等于预算时状态为“已达标”，否则为“未达标”。
- [ ] 每页 5 条。不能从本表下钻构成明细。
- [ ] 正数和负数使用对应颜色，单元格背景保持白色。

**业务规则：**

- **操作规则**：在全局范围内进一步多选船舶 → 刷新本表排序和分页，其他区域不变。
- **数据规则**：贡献毛利、已分配租金、贡献差额、当前实际值、指定差额、特殊航次贡献、燃油成本、排名、状态（计算）；年初指定值、跨年调整、船舶名称（选择带出）。跨年调整取上一年度贡献毛利，来源为 SAP。
- **校验规则**：只统计已完航或 POC。特殊航次贡献等于内贸货贡献加互租合同航次贡献，同一航次不重复累计。
- **状态逻辑**：本表船舶选择与全局筛选独立；全局船舶范围变小时，本表已选但不在范围内的船舶自动移除。
- **异常场景**：
  - 本表船舶选择超出全局范围 / 不允许保留越界船舶 / 不阻断表内其余船舶 / 自动移除
  - 当前筛选无船 / 展示空表 / 不阻断其他区域 / 无单独提示文案

**数据流与依赖：**

- **上下游模块/系统**：读取 Budget Analysis 的贡献、租金和全年预算；跨年调整读取 SAP 年度贡献；燃油成本读取报文和 SAP 油价。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：依赖预算、SAP 年度贡献和燃油数据已同步。
- **公用数据/表**：与经营总览、分船共用贡献和租金口径。
- **连带影响**：结果可被 US-CAL-014 导出，并按 US-CAL-015 分页。
- **权限与数据范围**：半潜财务人员，授权经营公司和船舶，只读。

**前置条件：**

- US-CAL-001 已形成有效全局范围。

**后置条件：**

- 用户看到当前筛选下的分船年度汇总和达标状态。

**关联 US：** 上游 US-CAL-001；下游 US-CAL-014、US-CAL-015；关联功能编号 F-CAL-005

### US-CAL-006：内贸货年度核算与收益成本明细

**作为** 半潜财务人员

**我想要** 核对内贸货航次的年度确认收益、成本、贡献和跨年状态

**以便于** 区分已确认金额和待确认航次，并找出跨年航次。

### US-CAL-013：就地异常提示

**作为** 半潜财务人员

**我想要** 在油耗对比和月度燃油核算上直接看到异常状态

**以便于** 区分正常、需关注和不能按 0 处理的数据问题。

**验收标准：**

- [ ] 不单独打开异常清单，也不生成处理建议。
- [ ] 各船月度油耗按 US-CAL-009 显示正常、关注、异常或“—”。
- [ ] 月度核算异常包括正常、库存为负、数量不平、单价异常、油耗异常、数据缺失。
- [ ] 同一核算行命中多项时，主状态优先级为：数据缺失、数量不平、库存为负、单价异常、油耗异常、正常。
- [ ] 库存为负指期末存油小于 0。数量不平指期初加本月加油减本月耗油与期末的差超过 5 吨。单价异常指实际加油价或移动加权均价相对市场价偏差超过 25%。油耗异常指分析月份单位油耗高于该船相同 VLSFO 近 6 个月平均单位油耗 10% 以上。

**业务规则：**

- **操作规则**：查看油耗区域或月度核算异常列 → 系统按规则显示状态；多项命中时可查看全部命中项。
- **数据规则**：油耗状态、月度异常情况（计算）。不新增用户录入字段。
- **校验规则**：油耗状态按偏差方向而不是绝对值。无法计算偏差率时不判断状态。
- **状态逻辑**：异常只改变标识，不回写源报文，不把负耗油或缺失成本改成 0。
- **异常场景**：
  - 同一月度核算行命中多项 / 按优先级展示一个主状态，并保留全部命中项 / 不阻断该行 / 主状态为优先级最高的类型
  - 无法计算油耗偏差率 / 状态显示“—” / 不计入异常船舶 / “—”

**数据流与依赖：**

- **上下游模块/系统**：消费 US-CAL-009 的油耗偏差和 US-CAL-010 的库存、数量、价格结果。不向外部系统发送异常。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：无独立同步。
- **公用数据/表**：与油耗分析和月度核算共用同一批耗油、库存和价格结果。
- **连带影响**：无待办、消息或单据状态变更。
- **权限与数据范围**：半潜财务人员，授权经营公司和船舶，只读。

**前置条件：**

- US-CAL-009 或 US-CAL-010 已算出对应区域的数据。

**后置条件：**

- 异常标识显示在原区域，源数据保持原值。

**关联 US：** 上游 US-CAL-009、US-CAL-010；关联功能编号 F-CAL-013
