## 二、POOL租金测算及结算模块

按功能清单 44 项功能逐条展开单功能契约。字段口径以关联功能清单附录 A 为准；正文只写业务文字描述。

### US-001：列表展示

**作为** 有菜单权限的用户

**我想要** 进入租金测算及结算菜单查看测算单列表

**以便于** 掌握权限范围内各期间测算单的最新状态和审批进度

**验收标准：**

- [ ] 草稿删除入口和确认流程见 US-051。
- [ ] （正常）列表仅展示当前用户组织/船东权限内、已成功创建且未物理删除的单据
- [ ] （异常）无数据权限的单据不出现在列表中，也不能通过列表看到
- [ ] （边界）同一单据存在多个提交版本时只展示当前最新版本；未保存完成的临时新建数据不入列表
- [ ] 展示序号、单据编号、测算类型、业务期间、状态、当前审批节点、发起人、更新时间、版本和操作
- [ ] 测算类型展示值为季度预估日租金、月度补充预估、年度年结调整
- [ ] 默认置顶优先，组内按更新时间倒序；序号按当前结果集从 1 重编
- [ ] 草稿当前审批节点显示「-」，审批中显示当前待审批角色，已完成显示「审批完成」，已退回显示退回节点

**业务规则：**

- **操作规则**：进入菜单 → 系统按权限加载最新版单据 → 列表展示单据字段
- **数据规则**（关键字段标来源性质）：序号（系统生成，当前结果集从 1 重编）；单据编号（系统生成，POOL-{类型代码}-{年度}-{三位流水号}，类型代码季度 Q、月度 M、年度 Y）；测算类型、业务期间、状态、当前审批节点、发起人、更新时间、版本（系统生成，只读）
- **校验规则**：无录入校验；列表不展示尚未保存完成的临时数据
- **状态逻辑**：所有状态均可查看；仅草稿和已退回对商务主管展示编辑入口
- **异常场景**（四元组）：
  - 用户无菜单权限 / 不进入本列表 / 阻断 / 按门户统一无权限提示（待确认）

**数据流与依赖：**

- **上下游模块/系统**：本功能读写测算单据列表或测算单据业务对象，细节见本条操作规则
- **第三方对接**：无
- **定时任务**：无
- **数据同步**：无
- **公用数据/表**：测算单据
- **连带影响**：无
- **权限与数据范围**：有菜单权限用户，数据范围为本组织/船东权限内测算单据；无敏感字段脱敏要求

**前置条件：**

- 用户已通过集团门户登录并具备本菜单权限

**后置条件：**

- 用户可从列表进入查看、编辑（若允许）或置顶

**关联 US：** 上游 无，下游 US-002、US-006、US-007、US-008；关联功能编号 F-LIST-001

### US-002：筛选查询

**作为** 有菜单权限的用户

**我想要** 按业务年度、测算类型和状态组合查询测算单

**以便于** 快速定位目标期间和状态的单据

**验收标准：**

- [ ] （正常）业务年度含「全部」及已有有效单据的年度，按倒序
- [ ] （异常）筛选条件未选全时按已选条件过滤，未选视为全部
- [ ] （边界）查询后回到第 1 页并提示命中条数
- [ ] 测算类型选项为全部、季度预估日租金、月度补充预估、年度年结调整，与列表展示值精确匹配
- [ ] 状态选项为全部、草稿、审批中、已完成、已退回；多条件同时满足；置顶记录在筛选结果中仍优先

**业务规则：**

- **操作规则**：展开筛选并选择条件后查询 → 系统按条件过滤并回第一页 → 提示条数并展示结果
- **数据规则**（关键字段标来源性质）：业务年度、测算类型、状态（用户选择，可筛选）
- **校验规则**：筛选值与列表展示值精确匹配
- **状态逻辑**：筛选不改变单据状态，仅改变当前结果集
- **异常场景**（四元组）：
  - 查询无命中 / 展示空列表并提示 0 条 / 不阻断 / 命中条数提示（待确认）

### US-005：置顶与取消置顶

**作为** 有菜单权限的用户

**我想要** 将关注单据固定在列表前部或取消固定

**以便于** 持续跟踪重点测算单

**验收标准：**

- [ ] （正常）点击置顶后该行移至列表前部并标记置顶样式
- [ ] （异常）无权限单据不可置顶
- [ ] （边界）置顶状态按用户维度保留；置顶组与普通组均按更新时间倒序
- [ ] 再次点击取消置顶后恢复普通排序；筛选结果中置顶仍优先

**业务规则：**

- **操作规则**：点击置顶或再点取消 → 单据固定前部或恢复排序 → 组内按更新时间倒序
- **数据规则**（关键字段标来源性质）：置顶标记（用户操作，按用户维度保留）
- **校验规则**：无
- **状态逻辑**：所有可见单据均可置顶/取消置顶，与单据审批状态无关
