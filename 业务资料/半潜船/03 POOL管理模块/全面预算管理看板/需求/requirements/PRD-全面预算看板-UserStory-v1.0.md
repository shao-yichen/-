## 二、看板通用能力



### US-001：看板加载与数据更新时间

**作为** 管理层、财务人员、项目管理人员或调度人员

**我想要** 在权限范围内加载全面预算看板并看到数据更新时间

**以便于** 判断当前分析所依据的数据是否足够新

**验收标准：**

- [ ] 正常：进入页面后展示滚动预算、航次效益、成本超支预警三个区域及精确到分钟的数据更新时间。
- [ ] 异常：某数据源失败时仅对应模块显示失败状态，其他可用模块正常展示，且不沿用误导性旧数据。
- [ ] 边界：不同来源更新时间不一致时，展示统一共同截止时间或分别明确标注。

**业务规则：**

- **操作规则**：进入页面 → 系统鉴权并加载数据 → 展示各模块和更新时间。
- **数据规则**：数据更新时间（系统生成）反映当前展示数据的实际截止时间。
- **校验规则**：无访问权限时不得返回看板业务数据。
- **状态逻辑**：加载中、成功、部分失败、整体失败须有明确状态。
- **异常场景**：数据源超时 / 展示对应模块失败并提供重试 / 不阻断其他模块 / 系统提示。

**数据流与依赖：**

- **上下游模块/系统**：读取预算、航次、财务和使费业务数据，向全部看板模块提供统一上下文。
- **第三方对接**：Budget Analysis、SAP、POC、Master Scenario 及港口使费相关数据服务，只读。
- **定时任务**：源数据刷新任务，频率待确认。
- **数据同步**：展示最近一次成功同步的数据及对应时间。
- **公用数据/表**：组织、船舶、航次和权限范围。
- **连带影响**：为筛选、下钻和导出提供数据快照。
- **权限与数据范围**：所有角色仅能加载授权组织、船舶及航次。

**前置条件：** 用户已登录并拥有看板访问权限。

**后置条件：** 页面形成可供查询、下钻或维护的看板上下文。

**关联 US：** 下游 US-005、US-010、US-014、US-016、US-022、US-024；关联功能编号 F-COM-001

**UI 原型：** `原型-全面预算看板-v1.4.html`

### US-002：指标单位与空值展示

**作为** 管理层、财务人员、项目管理人员或调度人员

**我想要** 看到单位、精度及空值规则一致的指标

**以便于** 正确比较不同卡片和图表的数据

**验收标准：**

- [ ] 正常：金额、比例和日均金额分别按万 USD、百分比、USD/天展示，并符合功能清单附录 A 的精度。
- [ ] 异常：关键值缺失或比例分母为空/为 0 时显示“—”，不得显示无穷大、NaN 或默认 0%。
- [ ] 边界：负数保留符号；0 作为有效金额显示，不能与空值混淆。

**业务规则：**

- **操作规则**：用户查看指标 → 系统换算并格式化 → 展示值和单位。
- **数据规则**：展示值（计算/系统换算）不得改变底层原始值。
- **校验规则**：参与同一比例计算的范围、币种和截止日期必须一致。
- **状态逻辑**：有效值显示数值；不可计算值显示“—”。
- **异常场景**：分母为空或为 0 / 不计算比例并显示“—” / 不阻断其他指标 / 无。

**数据流与依赖：**

- **上下游模块/系统**：消费所有指标结果，统一输出格式。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：沿用 US-001 数据快照。
- **公用数据/表**：币种、单位、精度和空值规则。
- **连带影响**：同步影响页面和 PDF 导出展示。
- **权限与数据范围**：不改变上游数据权限。

**前置条件：** 至少一个看板模块已返回数据。

**后置条件：** 页面及导出使用统一显示口径。

**关联 US：** 上游 US-001，下游 US-004；关联功能编号 F-COM-002

**UI 原型：** `原型-全面预算看板-v1.4.html`

### US-003：船名主数据选择器

**作为** 管理层、财务人员、项目管理人员或调度人员

**我想要** 按船舶代码、中文船名或英文船名查找并选择船舶

**以便于** 快速限定分析范围

**验收标准：**

- [ ] 正常：输入任一名称或代码可模糊匹配，结果展示序号、代码、中英文船名，支持选择和清除。
- [ ] 异常：无匹配结果时显示空状态，不保留上次结果。
- [ ] 边界：搜索忽略大小写和空格；单选再次点击可取消，全量航次场景支持多选。

**业务规则：**

- **操作规则**：打开选择器 → 搜索/翻页 → 选择或清除 → 刷新关联组件。
- **数据规则**：船名和船舶代码（选择带出）来自生产船舶主数据。
- **校验规则**：只返回用户有权查看的船舶。
- **状态逻辑**：默认“全部船名”；有选择时展示名称或已选数量。
- **异常场景**：主数据查询失败 / 关闭结果区并提示重试 / 阻断本次选择 / 无。

**数据流与依赖：**

- **上下游模块/系统**：从船舶主数据读取，供贡献毛利、期租、风险及账单模块消费。
- **第三方对接**：船舶主数据，只读。
- **定时任务**：无。
- **数据同步**：每次打开或按缓存策略读取最新有效主数据，策略待确认。
- **公用数据/表**：船舶代码、中文名、英文名、组织归属。
- **连带影响**：选择变化触发关联图表或列表刷新。
- **权限与数据范围**：全部角色可筛选，仅展示授权船舶。

**前置条件：** 看板已加载且用户拥有船舶数据权限。

**后置条件：** 当前组件保存有效船舶筛选条件。

**关联 US：** 上游 US-001，下游 US-011、US-015、US-019；关联功能编号 F-COM-003

**UI 原型：** `原型-全面预算看板-v1.4.html`

### US-004：导出 PDF 看板报告

**作为** 管理层或财务人员

**我想要** 将当前权限和筛选条件下的完整看板导出为 PDF

**以便于** 离线汇报、分享和归档

**验收标准：**

- [ ] 正常：PDF 包含三个看板区域、当前筛选条件下的完整分页结果、报告名称、生成时间、数据更新时间、筛选摘要和单位说明。
- [ ] 正常：采用横向版式，图表、图例、KPI、文字和表格无截断、重叠、溢出或明显模糊。
- [ ] 正常：主看板文件名为`全面预算看板_yyyyMMdd_HHmmss.pdf`；全量航次弹窗单独导出为`全部航次期租情况_yyyyMMdd_HHmmss.pdf`。
- [ ] 异常：生成或下载失败时保留筛选条件、提示原因并允许重试，不把不完整文件标记为成功。
- [ ] 边界：预计 5 秒内完成时同步下载；超过 5 秒时转为异步生成并反馈状态。

**业务规则：**

- **操作规则**：点击导出 → 固化当前数据快照及筛选 → 生成 PDF → 下载或反馈异步状态。
- **数据规则**：生成时间（系统生成）与数据更新时间（系统生成）分别标识；分页列表导出全部筛选结果。
- **校验规则**：必须校验导出权限、数据完整性和文件可读性。
- **状态逻辑**：按钮支持可用、生成中、成功和失败重试状态；项目管理人员和调度人员不可用。
- **异常场景**：PDF 渲染失败 / 终止下载并保留上下文 / 阻断 / 系统提示。

**数据流与依赖：**

- **上下游模块/系统**：消费全部看板模块的当前数据快照，输出 PDF 文件。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：不重新拉取数据，以用户点击时快照为准。
- **公用数据/表**：权限、筛选条件、数据更新时间、指标单位。
- **连带影响**：生成可下载文件，不修改业务数据。
- **权限与数据范围**：仅管理层、财务人员可导出，且不得突破当前数据权限。

**前置条件：** 看板加载完成；用户具备导出权限；不存在阻断导出的加载错误。

**后置条件：** 用户获得合规 PDF，或收到可重试的失败反馈。

**关联 US：** 上游 US-001、US-002、US-017、US-025；关联功能编号 F-COM-004

**UI 原型：** `原型-全面预算看板-v1.4.html`

### US-005：预算执行层级切换

**作为** 管理层、财务人员、项目管理人员或调度人员

**我想要** 在合资公司、半潜船经营部和单船层级间切换

**以便于** 从不同管理层级查看预算执行情况

**验收标准：**

- [ ] 正常：默认显示合资公司，切换后刷新指标、图表和口径说明。
- [ ] 异常：目标层级无数据时展示空状态，不沿用上一个层级数据。
- [ ] 边界：单船层级仅包含合资公司入 Pool 船舶，且不展示利润指标。

**业务规则：**

- **操作规则**：点击层级 → 清除不适用选择 → 加载对应数据 → 更新口径。
- **数据规则**：预算分析层级（用户选择）限定组织或船舶统计范围。
- **校验规则**：层级必须在枚举及用户权限范围内。
- **状态逻辑**：当前层级高亮；切换期间显示加载状态。
- **异常场景**：无。

**数据流与依赖：**

- **上下游模块/系统**：消费组织、入 Pool 船舶及权限范围，驱动 US-006～US-008。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：沿用 US-001 数据快照。
- **公用数据/表**：组织层级、入 Pool 标识、用户权限。
- **连带影响**：切换后更新 KPI、仪表盘、单船图及利润指标维护上下文。
- **权限与数据范围**：全部角色可查看授权范围；不可越权切换。

**前置条件：** US-001 已完成加载。

**后置条件：** 当前预算分析层级生效。

**关联 US：** 上游 US-001，下游 US-006、US-007、US-008、US-009；关联功能编号 F-BUD-001

### US-006：组织层级预算执行率

**作为** 管理层、财务人员、项目管理人员或调度人员

**我想要** 查看合资公司或半潜船经营部的预算执行率

**以便于** 掌握年度预算完成程度

**验收标准：**

- [ ] 正常：展示全年预算总额、截至数据更新时间的实际效益及“实际效益÷预算总额×100%”，比例至少 1 位小数。
- [ ] 异常：预算总额为空或为 0 时执行率显示“—”。
- [ ] 边界：全年预算不随月份切割；半潜船经营部实际效益仅统计已完航和 POC 航次并去重。

**业务规则：**

- **操作规则**：选择组织层级 → 汇总预算和实际效益 → 计算并展示执行率。
- **数据规则**：预算总额、实际效益（系统取数/汇总），金额为万 USD。
- **校验规则**：分子分母须同年度、同组织范围、同币种。
- **状态逻辑**：只读；随层级变化刷新。
- **异常场景**：预算为 0 / 显示“—” / 不阻断其他指标 / 无。

**数据流与依赖：**

- **上下游模块/系统**：读取 Budget Analysis 相关预算与实际效益数据。
- **第三方对接**：Budget Analysis，只读。
- **定时任务**：无。
- **数据同步**：随看板数据刷新。
- **公用数据/表**：组织、年度、航次状态。
- **连带影响**：结果进入 PDF 导出。
- **权限与数据范围**：所有角色仅查看授权范围。

**前置条件：** US-005 已确定组织层级。

**后置条件：** 形成组织预算执行结果。

**关联 US：** 上游 US-005，下游 US-004；关联功能编号 F-BUD-002

**UI 原型：** `原型-全面预算看板-v1.4.html`

- [ ] 异常：指标未维护、为空或为 0 时显示“—”。
- [ ] 边界：单船层级不展示利润指标数和完成率。

**业务规则：**

- **操作规则**：选择组织 → 读取当前有效利润指标 → 计算完成率。
- **数据规则**：利润指标数（用户录入）、实际效益（系统汇总），须同年度同组织。
- **校验规则**：分母必须大于 0。
- **状态逻辑**：只读；指标维护成功后即时刷新。
- **异常场景**：指标缺失 / 显示“—” / 不阻断预算执行率 / 无。

**数据流与依赖：**

- **上下游模块/系统**：消费 US-006 实际效益和 US-009 利润指标。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：利润指标保存后同步刷新。
- **公用数据/表**：年度、组织、当前有效利润指标。
- **连带影响**：结果进入 PDF 导出。
- **权限与数据范围**：所有角色可查看；仅管理层、财务人员可改变分母。

**前置条件：** 当前层级为合资公司或半潜船经营部。

**后置条件：** 展示可计算的利润指标完成率或“—”。

**关联 US：** 上游 US-006、US-009；关联功能编号 F-BUD-003

### US-028：到期日与逾期天数计算

**作为** 管理层、财务人员、项目管理人员或调度人员

**我想要** 查看统一计算的到期日和逾期天数

**以便于** 准确判断账单是否超过 90 天

**验收标准：**

- [ ] 正常：到期日＝凭证输入日期＋90 个自然日；逾期天数＝系统当前日期－到期日。
- [ ] 异常：凭证输入日期缺失或非法时两项结果显示“—”且账单不纳入超期统计。
- [ ] 边界：到期日当天逾期天数为 0 且不超期，次日为 1 并纳入。

**业务规则：**

- **操作规则**：读取日期 → 计算到期日 → 计算逾期天数 → 输出超期判定。
- **数据规则**：凭证输入日期（系统取数）；到期日、逾期天数（计算得出）。
- **校验规则**：使用自然日且系统日期来源一致。
- **状态逻辑**：每日动态重算，不固化逾期天数。
- **异常场景**：日期非法 / 显示“—”并排除 / 不阻断其他账单 / 无。

**数据流与依赖：**

- **上下游模块/系统**：读取账单日期，为 US-025 和 US-028 提供结果。
- **第三方对接**：港口使费账单数据服务，只读。
- **定时任务**：每日随系统日期更新。
- **数据同步**：凭证日期变化后重算。
- **公用数据/表**：账单号、凭证输入日期、系统日期。
- **连带影响**：决定超期资格和明细显示。
- **权限与数据范围**：所有角色只读。

**前置条件：** 账单包含可解析凭证输入日期。

**后置条件：** 输出到期日、逾期天数和超期资格。

**关联 US：** 下游 US-024、US-027；关联功能编号 F-BIL-005

### US-029：代理主数据标准化

**作为** 管理层、财务人员、项目管理人员或调度人员

**我想要** 看到统一的代理标准名称

**以便于** 避免同一供应商因多种名称被重复统计

**验收标准：**

- [ ] 正常：按供应商编码关联主数据并展示标准中文名称，用于筛选、排行和明细。
- [ ] 异常：映射失败时保留可识别源名称并标记待治理，不合并到错误代理。
- [ ] 边界：同一供应商多语言或历史名称均归入同一标准编码。

**业务规则：**

- **操作规则**：读取供应商编码 → 关联主数据 → 输出标准名称。
- **数据规则**：供应商编码、源名称（系统取数）；标准名称（选择带出）。
- **校验规则**：编码唯一；禁止仅按名称文本合并。
- **状态逻辑**：只读；主数据更新后重算汇总。
- **异常场景**：编码无映射 / 展示源名称并标记治理 / 不阻断明细 / 无。

**数据流与依赖：**

- **上下游模块/系统**：读取供应商主数据，向 US-027、US-028 提供标准名称。
- **第三方对接**：供应商主数据服务，只读。
- **定时任务**：主数据同步任务，频率待确认。
- **数据同步**：按供应商编码增量或全量同步，策略待确认。
- **公用数据/表**：供应商编码、标准中文名称、历史名称。
- **连带影响**：影响代理筛选、排行分组和明细展示。
- **权限与数据范围**：所有角色只读授权范围。

**前置条件：** 账单包含供应商编码。

**后置条件：** 代理名称标准化并可用于一致汇总。

**关联 US：** 下游 US-026、US-027；关联功能编号 F-BIL-006

**UI 原型：** `原型-全面预算看板-v1.4.html`
