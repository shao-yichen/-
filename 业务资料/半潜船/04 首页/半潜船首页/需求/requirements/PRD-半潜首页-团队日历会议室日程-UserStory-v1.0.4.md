## 一、团队日历 模块



### US-CAL-001：团队日历与会议室日程页签切换

**作为** 当前登录用户
**我想要** 在首页卡片内切换团队日历和会议室日程
**以便于** 不离开首页即可查看人员安排和会议室资源

**验收标准**：

- [ ] 默认进入团队日历页签时，展示日历、订阅入口、我的日程列表和创建按钮。
- [ ] 点击会议室日程页签后，隐藏团队日历相关内容，展示会议室筛选和时间轴。
- [ ] 再次切回团队日历页签后，恢复原团队日历视图状态。

**业务规则**：

- **操作规则**：用户点击页签 → 系统切换对应视图 → 用户查看目标日程内容。
- **数据规则**：当前页签（用户选择，取值为团队日历/会议室日程）；视图状态（系统记录，用于恢复展示）。
- **校验规则**：页签取值仅允许团队日历、会议室日程。
- **状态逻辑**：会议室日程页签下不展示创建日程按钮；团队日历页签下不展示会议室筛选工具条。
- **异常场景**：
  - 目标视图数据加载失败 / 系统保留当前页签并提示重试 / 不阻断页面使用 / 页面数据加载失败，请稍后重试

**数据流与依赖**：

- **上下游模块/系统**：无。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：无。
- **公用数据/表**：日程/会议数据、会议室占用数据。
- **连带影响**：影响创建按钮、订阅面板、会议室筛选区域的可见状态。
- **权限与数据范围**：当前登录用户可访问首页时可使用。

**前置条件**：

- 用户已登录并进入半潜首页。

**后置条件**：

- 首页卡片展示用户选择的目标页签内容。

**关联 US**：上游 无，下游 US-CAL-002、US-ROOM-001；关联功能编号 F-CAL-001

**UI原型**：
`半潜首页-团队日历会议室日程-原型-v1.5.html`

### US-CAL-002：团队日历周/月视图

**作为** 当前登录用户
**我想要** 在团队日历中切换周视图和月视图
**以便于** 按不同时间粒度查看本人和订阅人员安排

**验收标准**：

- [ ] 周视图展示一周 7 天和 0-24 点时间轴。
- [ ] 月视图展示 6 行日历格；格内当日事件按开始时间升序逐条展示（规则详见 US-CAL-004）。
- [ ] 点击上一周期、下一周期后，当前周或当前月正确变化；年月标签随周期更新。
- [ ] 点击日期后，更新选中日期，并同步刷新我的日程列表为该日「我的日程」。

**业务规则**：

- **操作规则**：用户切换周/月或日期 → 系统重绘日历 → 展示对应周期事件并联动我的日程列表。
- **数据规则**：视图类型（用户选择）；选中日期（用户点击）；周期范围（系统计算）。
- **校验规则**：视图类型仅允许周、月；日期必须为有效日历日期。
- **状态逻辑**：周视图按时间轴定位事件并可做忙闲聚合；月视图按日历格内逐条列表展示事件（不聚合）。
- **异常场景**：
  - 周期事件为空 / 系统展示空日历格 / 不阻断

**数据流与依赖**：

- **上下游模块/系统**：读取团队日历事件，驱动日程块展示和我的日程列表。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：无。
- **公用数据/表**：日程/会议数据、订阅成员范围。
- **连带影响**：更新我的日程列表和日程块展示。
- **权限与数据范围**：仅展示当前用户本人及订阅范围内的可见事件。

**前置条件**：

- 用户处于团队日历页签。

**后置条件**：

- 团队日历展示选中周期下的事件。

**关联 US**：上游 US-CAL-001，下游 US-CAL-003、US-CAL-007；关联功能编号 F-CAL-002

**UI原型**：
`半潜首页-团队日历会议室日程-原型-v1.5.html`

### US-CAL-003：日程块展示

**作为** 当前登录用户
**我想要** 在日历中看到本人和订阅人员相关事件
**以便于** 快速识别自己和团队成员的忙闲安排

**验收标准**：

- [ ] 展示范围：本人参与事件 + 已订阅成员相关事件。
- [ ] 本人参与事件使用「我的」样式（浅紫色色块）；仅订阅人员参与事件使用「订阅」样式（浅绿色色块）。
- [ ] 外出或全天出差类事件：周视图在日期头部展示，月视图格内按外出专用样式展示。
- [ ] 当前用户不可见的事件（参会人员可见且非参会人）标题显示为「忙碌」，不展示真实标题、地点、备注。
- [ ] 点击可见日程块可打开详情；点击不可见块可进入脱敏详情（时间、人员、忙碌状态）。

**业务规则**：

- **操作规则**：用户进入日历 → 系统读取事件与可见性 → 渲染不同样式日程块。
- **数据规则**：事件标题（用户录入/同步带出）；参与人员（用户选择/同步带出）；可见性（用户选择）；事件类型（用户选择/同步带出）。
- **校验规则**：不可见事件不得暴露标题、地点、备注。
- **状态逻辑**：本人参与优先使用「我的」样式；仅订阅成员参与使用「订阅」样式；外出/全天不参与周视图时间轴忙闲聚合。
- **异常场景**：
  - 事件对当前用户不可见 / 系统脱敏展示忙碌 / 不阻断 / 忙碌

**数据流与依赖**：

- **上下游模块/系统**：订阅成员范围、日程/会议数据、外部拜访计划同步数据。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：接收拜访计划同步事件。
- **公用数据/表**：人员信息、日程/会议数据。
- **连带影响**：支持详情查看和忙闲聚合。
- **权限与数据范围**：按参会人员可见/全员可见控制标题与详情展示。

**前置条件**：

- 已确定当前用户本人和订阅人员范围。

**后置条件**：

- 日历中按样式和可见性展示事件块。

**关联 US**：上游 US-CAL-002、US-CAL-005，下游 US-CAL-004、US-CAL-013；关联功能编号 F-CAL-003

**UI原型**：
`半潜首页-团队日历会议室日程-原型-v1.5.html`

### US-CAL-004：忙闲聚合展示

**作为** 当前登录用户
**我想要** 在周视图中看到重叠日程的聚合展示
**以便于** 快速判断多人同会和多事件冲突情况

**验收标准**：

- [ ] **仅周视图**做忙闲聚合；外出/全天出差类事件不参与时间轴聚合，仍在日期头部或月视图单独展示。
- [ ] 同一事件涉及多位订阅范围内成员时，界面仍展示**为一块**，不因多人拆成多个日程块；标题形如 `{事件标题}（{N}人）`。
- [ ] 聚合块三行展示：标题、人员摘要、时间段（组内最早开始～最晚结束）。
- [ ] 聚合块标题规则：仅 1 条且可见 → 事件标题；不可见 →「忙碌」；同一事件多人且可见 → `{标题}（{N}人）`；多条不同事件 → `{N}人忙碌`。
- [ ] 人员摘要最多展示 3 人姓名；超过 3 人追加「等」。
- [ ] 组内含本人参与 →「我的」浅紫样式；仅订阅成员 →「订阅」浅绿样式。
- [ ] 组内仅 1 个事件（含多人同会）点击后直接打开详情；多个不同事件点击后展开当前日期列。
- [ ] 展开后按事件去重并列排布；各块按真实起止时间定位；单块展示标题（或「忙碌」）、参与人员、时间段。
- [ ] 展开区域顶部提供「收起重叠日程」；展开时日列加宽约 420px，收起后恢复。
- [ ] **月视图不做聚合**：当日事件一行一条；按开始时间升序，开始相同则按结束时间升序；同开始时间不合并。
- [ ] 月视图条目格式为 `{开始时间} {标题}`；不可见标题为「忙碌」；超出格高可纵向滚动；点击进入详情。

**业务规则**：

- **操作规则**：用户查看周视图 → 系统按各成员时段识别重叠并合并忙闲组 → 渲染聚合块；用户点击后进详情或列内展开/收起。
- **数据规则**：事件开始/结束时间（用户录入/同步带出）；参与成员（用户选择/同步带出）；可见性（用户选择）；忙碌组起止（系统计算）。
- **校验规则**：后一条待合并项开始时间早于前一组结束时间则并入同一组；外出/全天事件不参与时间轴忙闲聚合。
- **状态逻辑**：单事件组点击进详情；多事件组点击展开并列明细；展开后可收起；月视图始终逐条竖向展示。
- **异常场景**：
  - 聚合组内存在不可见事件 / 系统标题显示忙碌并隐藏敏感信息 / 不阻断 / 忙碌

**数据流与依赖**：

- **上下游模块/系统**：读取本人及订阅范围内日程/会议事件。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：无。
- **公用数据/表**：日程/会议事件、人员信息、订阅范围。
- **连带影响**：影响详情入口和周视图列宽展示。
- **权限与数据范围**：不可见事件只展示忙碌、时间段和涉及人员，不得暴露真实标题、地点、备注。

**前置条件**：

- 用户处于团队日历；忙闲聚合规则作用于周视图。

**后置条件**：

- 重叠事件按聚合规则展示或展开；月视图按逐条规则展示。

**关联 US**：上游 US-CAL-003，下游 US-CAL-013；关联功能编号 F-CAL-004

**UI原型**：
`半潜首页-团队日历会议室日程-原型-v1.5.html`

### US-CAL-005：订阅日程

**作为** 当前登录用户
**我想要** 订阅半潜相关人员的日程
**以便于** 在团队日历中查看协作对象的忙闲

**验收标准**：

- [ ] 点击「订阅日程」按钮后展开订阅面板；按钮文案展示已订阅人数。
- [ ] 支持按项目组、部门、自定义团队快捷选择成员。
- [ ] 人员列表按组织架构分层展示；组织第一层包含：半潜船经营部、中远海运广州打捞局半潜船运输有限公司、中远海运半潜船（欧洲）有限公司。
- [ ] 点击组织行后，在该组织下方展开成员进行勾选。
- [ ] 支持按姓名或用户代码搜索；搜索时保留组织层级关系，并自动展开包含匹配成员的组织。
- [ ] 支持全选/取消全选。
- [ ] 已订阅人员以标签展示，可单个移除。
- [ ] 当前用户本人不作为可订阅人员，但本人日程默认展示。
- [ ] 可订阅成员限定为半潜相关人员（与创建会议、会议室预约参会人同一人员池）。

**业务规则**：

- **操作规则**：用户快捷选择或搜索勾选成员 → 系统更新标签和人数 → 团队日历刷新展示本人及订阅人员相关事件。
- **数据规则**：订阅成员（用户选择，限定半潜相关人员）；订阅人数（系统计算）；组织层级（选择带出）。
- **校验规则**：订阅成员范围限定为半潜相关人员；当前用户本人不可被订阅。
- **状态逻辑**：订阅面板展开后支持勾选、搜索、全选、取消全选和移除标签；移除标签后即时刷新日历。
- **异常场景**：
  - 搜索无匹配人员 / 系统展示空结果 / 不阻断 / 暂无匹配人员

**数据流与依赖**：

- **上下游模块/系统**：读取组织架构、项目组、部门、自定义团队和半潜相关人员池。
- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：无。
- **公用数据/表**：半潜相关人员池、组织架构、订阅关系。
- **连带影响**：刷新团队日历事件范围。
- **权限与数据范围**：本期不需要被订阅人单独授权，不另行做组织权限矩阵校验。

**前置条件**：

- 用户处于团队日历页签。

**后置条件**：

- 订阅范围保存并用于团队日历展示。

**关联 US**：上游 US-CAL-001，下游 US-CAL-003、US-CAL-006；关联功能编号 F-CAL-005

### US-CAL-006：自定义团队

**作为** 当前登录用户
**我想要** 创建、编辑、删除自己的自定义团队
**以便于** 在订阅和参会人选择时快捷复用成员组

**验收标准**：

- [ ] 入口为订阅面板中的「自定义团队」按钮；弹窗含「已有自定义团队」列表与新建/编辑表单。
- [ ] 新建：填写团队名称，从半潜相关人员勾选至少 1 名成员后保存。
- [ ] 编辑：列表提供编辑入口，可修改团队名称与成员列表后保存。
- [ ] 删除：列表提供删除入口，删除前二次确认；删除后仅移除快捷选项，不影响已有订阅关系及已创建日程/会议/会议室预约。
- [ ] 团队名称必填；同一用户下团队名称不可重复。
- [ ] 编辑团队成员后不同步已订阅列表或已创建事项，仅影响下次快捷选择的成员范围。
- [ ] 自定义团队仅当前用户可见；按当前用户持久化到后台，下次登录仍可使用。

**业务规则**：

- **操作规则**：用户新建/编辑/删除团队 → 系统校验并保存 → 自定义团队快捷下拉更新。
- **数据规则**：团队名称（用户录入，必填且同用户唯一）；团队成员（用户选择，至少 1 人，须为半潜相关人员）；归属用户（系统生成）。
- **校验规则**：名称必填、同用户唯一；成员须为半潜相关人员；成员数不少于 1。
- **状态逻辑**：新建、编辑、删除均只影响当前用户的快捷团队配置；删除不影响历史业务数据。

- **校验规则**：按分钟精度判断时间段相交；结束时间必须晚于开始时间；编辑时应排除当前记录自身；会议室冲突为阻断性校验（不同于人员冲突只提示）。
- **状态逻辑**：会议室冲突为阻断性异常。
- **异常场景**：
  - 时间段重叠 / 系统阻止保存 / 阻断 / 会议室已被占用：{会议室} {时间}「{标题}」

**数据流与依赖**：

- **第三方对接**：无。
- **定时任务**：无。
- **数据同步**：线下会议与会议室日程共享同一占用。
- **公用数据/表**：会议室占用数据。
- **连带影响**：阻止重复预约，保障会议室日程一致性。
- **权限与数据范围**：当前用户提交的会议室占用需与全量占用记录比对。

**前置条件**：

- 用户提交会议室预约或线下会议。

**后置条件**：

- 无冲突则允许保存；有冲突则阻止保存。

**验收标准**：
