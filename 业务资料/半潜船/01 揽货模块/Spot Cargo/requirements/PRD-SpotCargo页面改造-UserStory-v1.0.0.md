### US-SC-001：Firm Overview 视图切换

**作为** 业务人员

**我想要** 在列表页切换 Firm Overview 视图并隐藏 Status 图例

**以便于** 集中查看全部项目核心字段而不被状态图例占用空间

**验收标准：**

- [ ] Export 按钮左侧展示 `Firm Overview` 按钮
- [ ] 点击后按钮为选中态，列表切换为 Firm Overview 列布局
- [ ] Firm Overview 下顶部 Status 图例（Open/Firm/Fixed/Booked/Closed/Lost）隐藏
- [ ] 再次点击恢复默认列表视图，图例重新显示
- [ ] 页面标题保持 Spot Cargo
- [ ] 视图切换不清空已设置的筛选条件

**业务规则：**

- **操作规则**：点击 `Firm Overview` → 切换视图与按钮选中态；再次点击 → 恢复默认列表与图例
- **数据规则**：列表数据（用户录入/系统生成，与默认列表同源）；视图状态（用户操作，按会话或持久化展示）
- **校验规则**：无额外校验
- **状态逻辑**：Firm Overview 选中时隐藏 Status 图例；默认列表时图例可见
- **异常场景**：
  - 无数据时切换视图 / 展示空列表 / 不阻断 / 无提示

**数据流与依赖：**


| 维度       | 内容                             |
| -------- | ------------------------------ |
| 上下游模块/系统 | 读取 Spot Cargo 列表货盘数据；不写业务对象    |
| 第三方对接    | 无                              |
| 定时任务     | 无                              |
| 数据同步     | 无                              |
| 公用数据/表   | 与默认列表共用同一货盘数据集                 |
| 连带影响     | 联动 F-SC-003 筛选区布局、F-SC-002 列展示 |
| 权限与数据范围  | 沿用 Spot Cargo 列表访问权限           |


**前置条件：**

- 用户已进入 Spot Cargo 列表页

**后置条件：**

- 列表按所选视图渲染；Status 图例显示/隐藏与视图一致

**关联 US：** 下游 US-SC-002、US-SC-003；关联功能编号 F-SC-001

**UI 原型：** `Spot-Cargo-v1.5.html`

### US-SC-002：Firm Overview 列表展示与排序

**作为** 业务人员

**我想要** 在 Firm Overview 查看去重后的货盘核心列并排序

**以便于** 快速定位项目并维护关键信息

**验收标准：**

- [ ] 列字段：No.、Project Name、Vessel、LAYCAN、POL、POD、Freight、Recap、PIC、Operate
- [ ] 同一 PID 仅展示一条记录
- [ ] No. 按当前结果跨页连续编号（默认每页 20 条）
- [ ] Project Name、Vessel、LAYCAN、POL、POD、Freight、PIC 支持升序/降序/取消排序
- [ ] Recap 列不提供排序
- [ ] 置顶记录始终排在非置顶记录之前
- [ ] POL、POD、Freight、Recap 支持列表内快捷编辑

**业务规则：**

- **操作规则**：切换 Firm Overview → 展示核心列；点击列头 → 升序/降序/取消（Recap 除外）
- **数据规则**：No.（系统生成，跨页连续）；货盘各列（用户录入/选择带出/计算得出）；Freight 展示 Total Freight
- **校验规则**：排序仅作用于当前筛选结果
- **状态逻辑**：置顶区始终位于非置顶记录之前；Recap 列头无排序控件
- **异常场景**：
  - 筛选结果为空 / 展示空列表 / 不阻断 / 无提示

**数据流与依赖：**


| 维度       | 内容                                     |
| -------- | -------------------------------------- |
| 上下游模块/系统 | 读取货盘列表；快捷编辑写入货盘 POL/POD/Freight/Recap  |
| 第三方对接    | 无                                      |
| 定时任务     | 无                                      |
| 数据同步     | 快捷编辑与编辑页、默认列表双向同步（见 US-SC-004/005/006） |
| 公用数据/表   | 与默认列表、编辑页共用货盘数据                        |
| 连带影响     | 与 US-SC-007 置顶排序联动                     |
| 权限与数据范围  | 仅展示授权范围内货盘；编辑需货盘编辑权限                   |


**前置条件：**

- 已切换至 Firm Overview 视图（US-SC-001）

**后置条件：**

- 列表展示符合筛选、去重、排序与置顶规则

**关联 US：** 上游 US-SC-001；下游 US-SC-004/005/006/007；关联功能编号 F-SC-002

### US-SC-003：Firm Overview 筛选区

**作为** 业务人员

**我想要** 在 Firm Overview 使用精简筛选条件

**以便于** 按项目、船舶、航线和时间快速过滤

**验收标准：**

- [ ] Firm Overview 下筛选区仅展示 Project Name、Vessel、LAYCAN、POL、POD、PIC
- [ ] 默认列表视图仍展示完整原筛选条件
- [ ] LAYCAN 按项目发运区间与筛选区间交集匹配，边界包含当日
- [ ] 只填开始/结束日期时使用开放区间规则
- [ ] 填写任一 LAYCAN 日期后，无 LAYCAN 的记录不命中
- [ ] 开始日期不能晚于结束日期

**业务规则：**

- **操作规则**：切换 Firm Overview → 筛选区收缩；输入条件并查询 → 刷新列表
- **数据规则**：筛选条件（用户录入）；LAYCAN 发运区间（选择带出，来自货盘）
- **校验规则**：开始日期 ≤ 结束日期；违反时提示并禁止查询
- **状态逻辑**：Firm Overview 下隐藏的筛选字段不参与当前筛选
- **异常场景**：
  - 开始日期晚于结束日期 / 提示校验错误 / 阻断查询 / 无提示
  - 筛选后无命中 / 展示空列表 / 不阻断 / 无提示

**数据流与依赖：**


| 维度       | 内容                                  |
| -------- | ----------------------------------- |
| 上下游模块/系统 | 读取货盘 LAYCAN/POL/POD 等；筛选结果驱动列表展示    |
| 第三方对接    | 无                                   |
| 定时任务     | 无                                   |
| 数据同步     | 与 US-SC-007 置顶联动：筛选后不展示不符合条件记录（含置顶） |
| 公用数据/表   | 货盘 Project info 字段                  |
| 连带影响     | 重置筛选后置顶记录可重新出现                      |
| 权限与数据范围  | 授权范围内货盘                             |


**前置条件：**

- Firm Overview 视图已激活

**后置条件：**

- 列表仅展示命中筛选条件的记录

**关联 US：** 上游 US-SC-001；关联 US-SC-007；关联功能编号 F-SC-003

### US-SC-004：Freight 快捷修改

**作为** 业务人员

**我想要** 在列表直接修改 Total Freight 金额和币种

**以便于** 不必进入详情页即可更新运费

**验收标准：**

- [ ] 默认列表与 Firm Overview 的 Freight 列均支持金额+币种编辑
- [ ] 展示 Total Freight 金额（千分位）与 Currency
- [ ] 金额仅允许数字；币种通过选择器选择，不支持自由文本
- [ ] 修改后同步编辑页 Total Freight 与 Currency
- [ ] 任一视图修改后另一视图展示最新值
- [ ] 金额非数字时阻止保存

**业务规则：**

- **操作规则**：列表点击 Freight → 编辑金额/币种 → 失焦或确认 → 持久化并同步
- **数据规则**：Total Freight（计算得出，= Net Freight + Extra Cost）；Currency（用户录入/选择带出）；列表展示 Total Freight 非 Net Freight
- **校验规则**：金额必须为数字；币种必须从系统币种列表选择
- **状态逻辑**：两视图 Freight 展示始终一致
- **异常场景**：
  - 金额输入非数字 / 判断格式错误 / 阻断保存 / 无提示

**数据流与依赖：**


| 维度       | 内容                                              |
| -------- | ----------------------------------------------- |
| 上下游模块/系统 | 读写货盘 Commercial 运费；与 US-SC-024 联动               |
| 第三方对接    | 无                                               |
| 定时任务     | 无                                               |
| 数据同步     | 列表 ↔ 编辑页 Total Freight、Currency 双向同步            |
| 公用数据/表   | Commercial 运费四字段                                |
| 连带影响     | 修改 Total Freight 不自动拆分 Net Freight / Extra Cost |
| 权限与数据范围  | 需货盘编辑权限                                         |


**前置条件：**

- 用户对货盘有编辑权限

**后置条件：**

- Total Freight 与 Currency 已持久化；列表与详情一致

| 权限与数据范围  | 通知仅发送当前货盘 PIC                |
