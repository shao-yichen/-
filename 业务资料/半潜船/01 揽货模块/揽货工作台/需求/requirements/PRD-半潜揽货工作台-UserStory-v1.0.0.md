## 二、半潜揽货工作台模块

按关联功能清单 29 项功能逐条展开单功能契约。字段业务口径以功能清单附录 A 和《关于半潜揽货工作台指标口径-v1.1》为准。

### US-001：“我要办理”展开/收起

**作为** 半潜揽货业务用户

**我想要** 展开或收起“我要办理”快捷区

**以便于** 根据当前任务需要在快捷办理入口与下方数据区域之间分配页面空间

**验收标准：**

- [ ] （正常）默认进入页面时“我要办理”内容区可见。
- [ ] （边界）若展开状态切换失败，不得影响下方“需关注 / 我的跟进”和审批区域继续使用。
- [ ] （边界）连续多次点击仅在展开/收起两态间切换，不新增或丢失快捷入口。
- [ ] 点击右上角控件后，内容区隐藏；控件状态/方向同步变化。
- [ ] 再次点击后内容区恢复，所有快捷入口保持原有内容。
- [ ] 展开/收起不得改变“需关注”“我的跟进”或审批区域的筛选和数据状态。

**业务规则：**

- **操作规则**：点击展开/收起控件 → 系统切换快捷办理内容区显隐 → 同步更新控件视觉状态。
- **数据规则**（关键字段标来源性质）：展开状态（系统维护的页面状态，系统维护）。
- **校验规则**：控件仅存在展开/收起两态，不允许出现内容区与控件状态不一致。
- **状态逻辑**：展开/收起只影响显示状态，不触发业务数据加载或修改。
- **异常场景**（四元组）：无。展开/收起失败时维持当前可用状态，不影响其他模块。

**数据流与依赖：**

- **上下游模块/系统**：半潜揽货工作台快捷办理区
- **第三方对接**：无
- **定时任务**：无
- **数据同步**：无
- **公用数据/表**：“我要办理”展开/收起状态
- **连带影响**：仅影响快捷区显隐，不修改业务数据
- **权限与数据范围**：可进入半潜揽货工作台的授权用户

**前置条件：**

- 用户已进入半潜揽货工作台。

**后置条件：**

- “我要办理”保持用户最后一次点击后的展开或收起状态；其他区域状态不变。

**关联 US：** 上游 无，下游 US-002、US-003、US-004；关联功能编号 F-QUICK-001

**UI 原型：**

半潜揽货工作台-原型-v1.5.html

### US-002：Scenario 快捷入口

**作为** 具备 Scenario 页面权限的业务用户

**我想要** 从工作台直接进入 Master Scenario、Personal Scenario 或 Competitor Scenario

**以便于** 减少通过菜单逐层定位场景方案页面的操作

**验收标准：**

- [ ] （正常）Scenario 分组展示 Master Scenario、Personal Scenario、Competitor Scenario 3 个入口。
- [ ] （边界）当前用户无目标 Scenario 页面权限时，不展示对应入口。
- [ ] （边界）三个 Scenario 入口分别对应唯一目标页面，点击一个入口不得触发其他入口。
- [ ] 点击任一入口时，生产目标为进入对应源页面并使用当前登录用户身份。
- [ ] 进入源页面后的可见和可操作范围沿用该源页面既有权限。

**业务规则：**

- **操作规则**：用户点击目标 Scenario 入口 → 工作台发起页面路由 → 源页面按当前用户权限加载。
- **数据规则**（关键字段标来源性质）：入口名称（系统配置/页面固定展示）；当前登录用户（登录态带出）。
- **校验规则**：入口与目标页面必须一一对应；无目标页面权限时不展示对应入口。
- **状态逻辑**：工作台不维护 Scenario 业务状态；跳转后状态由源页面管理。
- **异常场景**（四元组）：无。无目标页面权限时不展示对应入口，属权限过滤，不按异常处理。

**数据流与依赖：**

- **上下游模块/系统**：半潜揽货工作台 → Master / Personal / Competitor Scenario
- **第三方对接**：无
- **定时任务**：无
- **数据同步**：无业务数据同步，仅页面导航
- **公用数据/表**：当前登录用户、源页面路由及权限配置
- **连带影响**：打开目标源业务页面，不修改工作台或源业务数据
- **权限与数据范围**：工作台入口权限 + 目标源页面既有权限

**前置条件：**

- 用户已进入半潜揽货工作台，且目标源页面入口可见。

**后置条件：**

- 系统进入对应源业务页面；后续可见/可操作范围由源页面权限控制。

**关联 US：** 上游 US-001，下游 无；关联功能编号 F-QUICK-002

**UI 原型：**

- [ ] （正常）默认进入中部区域时“需关注”处于选中状态。
- [ ] （边界）目标视图无可见数据时仍可正常切换，目标区域显示其对应空状态。
- [ ] （边界）任一时刻仅“需关注”或“我的跟进”一个视图处于激活状态，切换不修改源货盘/项目。

- **状态逻辑**：“需关注”和“我的跟进”互斥激活；切换只改变当前视图，不修改源业务记录。

**数据流与依赖：**
