## 二、LOI Register 模块

### US-001 · OCR Scan 识别回填

**作为** 有权新建或编辑 LOI Contract 的业务人员

**我想要** 上传 Heavycon 合同或基于我方模板编制的 LOI，由系统识别并回填对应字段，且可以手动修改

**以便于** 减少重复录入，并在保存前核对合同信息

**验收标准**

- [ ] 通过 LOI Register 的 New 入口新建合同，或打开有权编辑的已有合同后，Save 左侧显示带扫描图标的 OCR Scan 按钮。点击后可选择并上传文件。
- [ ] 分别上传有效的 Heavycon 合同和我方模板 LOI，系统按各自确认的字段映射自动回填。
- [ ] 对已有内容的对应字段，本次识别取得有效结果后直接覆盖。用户可修改回填结果，Save 使用提交时的表单值。
- [ ] 取消选择文件时保留表单当前内容。文件上传失败、文档无法识别或整次识别失败时，系统提示失败并保留表单当前内容，包括编辑时已手动修改的值。用户可重新扫描或继续手动录入。
- [ ] 部分字段有有效识别结果时，仅更新这些字段，未取得有效结果的字段保留扫描前的值。

**业务规则**

- **操作规则**：点击 OCR Scan，选择并上传文档，系统识别并回填，用户可复核和修改。
- **数据规则**：源文档（用户上传）包括 Heavycon 合同和我方模板 LOI。对应字段（系统识别回填、用户录入）沿用各字段格式和取值规则。本次识别取得有效结果时直接覆盖对应字段，未取得有效结果的字段保留原值。回填后仍可手动修改。
- **校验规则**：保存按现有表单规则校验。允许的上传文件格式和两类文档的解析样本待确认。识别结果按文档映射及现有字段规则回填。
- **状态逻辑**：选定文档后进入处理，成功后回填，失败后可重试。处理期间防止重复触发，沿用原型交互，待评审确认。
- **异常场景**：
  - 用户取消选择 / 返回当前表单并保留已有值 / 结束本次扫描操作 / 无。
  - 上传失败、文档无法识别或整次识别失败 / 提示失败、保留表单当前值并允许重新扫描 / 阻断本次回填，仍可手动录入 / Document scan failed, try scanning again or enter the details manually。

**数据流与依赖**

- **上下游模块/系统**：读取用户上传的源文档，将识别值写入当前合同表单。
- **第三方对接**：OCR 服务及接入方式待确认。
- **定时任务**：无。
- **数据同步**：无已定义的跨系统同步需求。
- **公用数据/表**：当前 LOI Contract 表单，与 Save 共用。
- **连带影响**：识别结果直接更新对应表单字段，由用户发起 Save。
- **权限与数据范围**：沿用系统统一权限。市场营销人员可对授权合同执行扫描与表单编辑。项目管理人员及其他获授访问权限的人员按实际获授的操作权限执行。

**前置条件**

- 用户已通过 New 进入新建页面，或已打开有权编辑的已有合同。

**后置条件**

- 识别结果已回填至对应字段，用户可继续编辑并保存。

**关联 US**：上游无，下游无，关联 F-LOI-001。

**UI 原型**：[LOI Register-原型-v1.0.html](./LOI%20Register-原型-v1.0.html) 

### US-002 · 测算表附件

**作为** 有权在新建或编辑 LOI Contract 时上传附件的业务人员

**我想要** 在 Attachment Info 的附件类型中选择“测算表”并按需上传

**以便于** 归档已有测算文件，并在暂无测算表时继续保存合同

**验收标准**

- [ ] 在新建或编辑合同页面打开 Attachment Info 的 Upload 弹窗，附件类型下拉框可直接选择“测算表”，也可搜索“测算表”后选择，原有类型仍可选择。
- [ ] 选择“测算表”并上传有效文件后，附件类型记录并显示为“测算表”。
- [ ] 测算表上传失败时，沿用现有失败反馈，用户可重新上传，附件区未增加一条成功上传的测算表记录。
- [ ] 新建或编辑合同时，其他保存条件均满足且当前合同没有测算表，点击 Save 仍能成功保存。

**业务规则**

- **操作规则**：打开 Upload 弹窗，直接选择或搜索选择“测算表”，选择文件并上传。
- **数据规则**：附件类型（用户选择）记录为“测算表”，附件文件（用户上传）关联当前合同。
- **校验规则**：主动上传时沿用现有附件上传校验，Save 无需校验是否已上传测算表。
- **状态逻辑**：上传成功后在 Attachment Info 显示附件及其类型。未上传时可按现有条件保存合同。
- **异常场景**：
  - 文件校验或上传失败 / 沿用现有失败处理并允许重新上传 / 阻断本次附件上传，测算表缺失本身不阻断 Save / 沿用现有上传提示。

**数据流与依赖**

- **上下游模块/系统**：读取用户选择的类型和文件，写入当前合同附件信息并展示。
- **第三方对接**：无新增对接需求。
- **定时任务**：无。
- **数据同步**：无新增跨系统同步需求。
- **公用数据/表**：现有附件类型选项、当前合同附件信息。
- **连带影响**：上传成功后更新 Attachment Info 的附件展示。
- **权限与数据范围**：沿用系统统一权限。市场营销人员可为授权合同选择附件类型并上传。项目管理人员及其他获授访问权限的人员按实际获授的操作权限执行。

**前置条件**

- 用户已进入新建或编辑 LOI Contract 页面，并有当前合同的附件上传权限。

**后置条件**

- 上传成功后，当前合同的附件信息记录并显示“测算表”类型。

**关联 US**：上游无，下游无，关联 F-LOI-002。

**UI 原型**：[LOI Register-原型-v1.0.html](./LOI%20Register-原型-v1.0.html)
