## 二、合同模板管理模块

### US-001 基础查询

**作为**市场营销人员或项目管理人员  
**我想要**按条件查找有效模板  
**以便于**定位所需合同模板

**验收标准**

- [ ] 正常场景。展开筛选区并填写条件，点击 Query 后生成基础结果，重新应用仍有效的表头筛选和排序，并返回第一页。
- [ ] 异常场景。无匹配时，系统显示空结果。
- [ ] 边界条件。条件全空时覆盖全部有效模板；客户从主数据单选，不能自由录入。

**业务规则**

- **操作规则** 展开筛选区并填写条件，点击 Query 后生成基础结果，重新应用仍有效的表头筛选和排序，并返回第一页。
- **数据规则** Template Name、Template Code、Customer Name 按包含匹配且忽略大小写；Updated Time 按北京时间的自然日匹配；三类 Category 精确匹配；条件间取交集，Tag 多选须全部命中。字段来源见功能清单附录 A。
- **校验规则** Template Name、Template Code、Customer Name 按包含匹配且忽略大小写；Updated Time 按北京时间的自然日匹配；三类 Category 精确匹配；条件间取交集，Tag 多选须全部命中。
- **状态逻辑** 条件全空时覆盖全部有效模板；客户从主数据单选，不能自由录入。
- **异常场景** 无匹配 / 显示空结果 / 不阻断 / 尚未检索到相关合同模板。

**数据流与依赖**

- **上下游模块/系统** 合同模板管理读取客户主数据并在本模块使用选择结果。
- **第三方对接** 无已定义对接。
- **定时任务** 无。
- **数据同步** 无已定义的跨系统写回。
- **公用数据/表** 有效模板、客户主数据。
- **连带影响** 无已定义的额外影响。
- **权限与数据范围** 市场营销人员、项目管理人员可操作全部模板，无需单独授权。

**前置条件**

- 已进入合同模板查询页。

**后置条件**

- 产生基础查询结果。

**关联 US** 下游 US-003，关联功能 F-CT-001。

**UI 原型** [合同模板管理原型](../合同模板管理-原型-v1.0.html)
